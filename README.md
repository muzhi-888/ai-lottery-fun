# 装修避坑大师

输入你的装修阶段、预算、城市，给出该阶段的增项预警、合同红线、材料选购要点，帮你少花冤枉钱。

## 它能帮你做什么

- 拆解装修各阶段的高频坑：报价虚高、增项套路、以次充好、工期拖延
- 给出合同必须写清的条款清单
- 提示材料选购与验收要点
- 提醒预算分配的常见误区

## 怎么用

1. 说明你处于哪个阶段（设计 / 报价 / 签约 / 施工 / 验收）
2. 描述你的预算和房型
3. 拿到一份阶段避坑清单和下一步动作

## 适合谁

- 准备装修或正在装修的业主
- 想自己盯工地、不想被牵着走的普通人
- 帮父母把关老房改造的子女

## 合规边界

- 仅作经验参考，不构成法律或专业建议
- 不荐具体商家、不承诺效果
- 决策与风险自行承担
